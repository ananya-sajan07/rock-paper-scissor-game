# Rock Paper Scissors Game

A simple rock, paper, scissors game written in Python. The player competes against the computer.

## How to Play:
1. Run the `rock-paper-scissors-game.py` script.
2. Enter one of the choices: `s` for Snake (Rock), `w` for Water (Paper), or `g` for Gun (Scissors).
3. The program will tell you if you win, lose, or tie based on your input.

## Requirements:
Python 3.x
